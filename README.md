# مَسَار | التأهيل المتكامل

مَسَار مساحة عربية للتأهيل والتعلّم العملي، تساعد المستخدم على فهم ما يريد تغييره، وكتابة خطة، وتنفيذ خطوة قابلة للقياس، ومراجعة تقدمه.

## المسارات الخمسة
- N1 التأهيل النفسي والشخصي
- N2 التأهيل الاجتماعي والعلاقات
- N3 التأهيل الرياضي والهوايات الفردية
- N4 التأهيل العاطفي
- N5 التأهيل الاقتصادي والعملي والعلمي

## فلسفة مَسَار
1. افهم وضعك.
2. اكتب خطة تناسب ظروفك.
3. نفّذ خطوة واضحة قابلة للقياس.
4. راجع ما تعلمته وعدّل خطوتك التالية.

التطبيقات والدورات الخارجية أدوات مساندة عندما تخدم خطة المستخدم، وليست بديلًا عن تجربة التأهيل داخل مَسَار. وأي روابط إحالة تجارية يجب أن تكون معتمدة وأن تتضمن إفصاحًا واضحًا عن العمولة. بطاقات المسار N5 موجودة كمسودات غير منشورة حتى اعتماد روابط التتبع ومراجعة شروط البرنامج.

## ملاحظات الحالة
الموقع واجهة تفاعلية قيد التطوير. يحفظ التقدم محليًا في المتصفح على الجهاز نفسه؛ لا يوجد في هذه النسخة حساب مستخدم أو مزامنة بين الأجهزة. لا تعتبر هذه الصفحة إثباتًا لاكتمال اختبارات جميع الوظائف أو خدمة توليد الفيديو.

## المشاركة المجتمعية
يمكن مشاركة صفحة التعريف مع المهتمين، وجمع ملاحظاتهم حول وضوح المسارات وسهولة تنفيذ الخطوة الأولى. لا تُقدّم المنصة باعتبارها خدمة علاجية أو بديلًا عن المختصين.
